# 全网日抛货源价格查询

全网日抛货源查询是一款面向发卡网商家的 Windows 与 Android 工具，主要用于搜索货源广场和公开店铺商品、筛选商品；Windows 版另外提供收藏、价格变化记录和商品关联。

软件在本机运行，登录和商品数据来自链动小铺官方页面及商家接口。本项目为非官方工具，与链动小铺不存在隶属或合作关系。

## 平台版本区别

- Windows 版提供完整功能，包括收藏、查询方案、CSV、三天价格曲线、变化监控和商品关联管理。
- Android 版是体积优先的查询版，保留三种查询范围、筛选排序、分页、公开店铺管理和默认浏览器详情跳转。
- Android 版不包含收藏、价格曲线、变化记录、CSV、查询方案、关联、取消关联或关联体检，也不会调用对应写接口。
- 两个平台的公开店铺库各自保存在本机，不进行云同步。

## 主要功能

### 货源查询与筛选

- 提供“货源广场”“公开店铺”“全部数据”三种查询范围。
- 根据关键词和商品类型拉取货源，支持设置拉取页数。
- 提供快速、标准、稳定三档拉取速度。
- 支持售价上下限、库存、商品状态、关联状态、分类和商家筛选。
- 支持设置屏蔽词，自动隐藏名称、分类或商家中包含屏蔽词的商品。
- 支持售价从低到高、从高到低排序，以及本地分页和跨页去重。
- 查询失败或取消时保留上一次成功结果。

### 公开店铺库

- 可粘贴 `https://www.ldxp.cn/item/...` 商品链接或 `https://pay.ldxp.cn/shop/...` 店铺链接。
- 粘贴商品链接时会先反查所属店铺，再把该店当前公开商品收录到本机店铺库。
- Windows 和 Android 均支持刷新单个店铺、刷新全部店铺及移除店铺。
- Windows 版另外支持通过 JSON、TXT 或 CSV 导入店铺链接，以及导出店铺列表；Android 版不提供文件导入导出。
- “公开店铺”范围只搜索本机已经收录的店铺；新增或刷新后重新查询即可看到最新结果。
- “全部数据”会合并货源广场和本地公开店铺结果；同一商品重复出现时优先保留货源广场记录。

> 公开店铺并不是全网实时索引。链动小铺目前没有公开、稳定的全站商品搜索接口，因此需要先用已知商品或店铺链接建立本地店铺库。

### 数据来源与字段限制

- 每条结果都会标记为“货源广场”或“公开零售”。
- 货源广场记录可显示平台返回的成本价、最低售价限制和关联状态，并可在明确确认后执行关联或取消关联。
- 公开零售记录只展示公开页面可见的售价、库存、销量、分类和店铺等字段。
- 公开零售记录不伪造成本价或关联状态，统一显示“不可关联”，也不会出现关联、取消关联和关联体检按钮。

### 收藏与查询方案

- 收藏任意数量的商品。
- 为收藏商品添加备注和自定义标签。
- 按商品名称、商家、备注或标签搜索收藏内容。
- 保存多个查询方案，一键恢复关键词、页数、速度和筛选条件。
- 将当前筛选结果导出为 CSV，可直接使用 Excel 打开。

### 三天价格历史

- 保存收藏商品最近 3 天的售价、成本价和库存记录；刷新公开店铺时也会更新其中已收藏商品的公开售价和库存。
- 同一商品在 30 分钟内被多次查询时，售价和成本价分别保留最低值。
- 通过价格曲线查看收藏商品近期变化。
- 每次查询成功后，会补充刷新本次结果中没有出现且上次仍有库存的收藏商品。

### 价格与库存监控

- 显示售价、成本价、库存、状态和关联状态相较上次的变化。
- 可提示“售价较上次降低 2 元”“库存从 0 恢复到 15”等信息。
- 只有覆盖平台全部页面并完整成功的查询才会生成变化比较，避免断网或只拉取部分页面时误报下架。
- 已收藏或已关联商品从完整结果中消失时，会提示可能下架或离开当前货源范围。

### 商品关联与体检

- 支持将单个货源商品关联到自己的店铺，也支持取消关联。
- 关联前需要明确确认，不会在后台静默执行。
- 关联时可设置分类、商品名称、描述、百分比加价、固定加价、售价跟随和同步选项。
- 关联体检可检查货源状态、成本上涨、关联售价与成本差额、最低售价限制、名称/描述同步状态和关联链接可用性。
- 体检本身是只读操作，不会自动修改商品或售价。

### 本地数据与账号安全

- 密码、短信验证码等登录信息只在链动小铺官方登录窗口中输入。
- Windows 登录凭证由系统加密服务保护；Android 登录凭证由 Android Keystore 使用 AES-GCM 加密保护。
- 收藏、备注、查询方案、价格历史和监控记录保存在本机，不上传到本项目的远程服务器。
- 不包含快捷购买、自动创建订单、自动付款、验证码绕过或风控绕过功能。

## 运行要求

### Windows

- Windows 10 或 Windows 11，64 位系统。
- 能正常访问链动小铺网站的网络环境。
- 已注册并完成小店开通的链动小铺商家账号；货源广场接口需要有效商家登录态，公开店铺数据则来自公开页面接口。

### Android

- Android 10 或更高版本。
- 系统已安装并启用 Android System WebView 和默认浏览器。
- 能正常访问链动小铺网站，并具有已开通小店的商家账号。

当前版本不支持 iOS、macOS 和 32 位 Windows。

## 下载与安装

前往项目的 [Releases 页面](https://github.com/CUy-y/source-browser-desktop/releases/latest)，在 `Assets` 中选择需要的版本：

- `链动货源查询-版本号-x64-Setup.exe`：安装版，适合长期使用，可选择安装目录并创建桌面快捷方式。
- `链动货源查询-版本号-x64-Portable.exe`：便携版，不需要安装，下载后可直接运行。
- `链动货源查询-1.9.0-android-debug.apk`：Android 查询测试版；如果该文件已附加到 Release，可在手机浏览器下载后按系统提示安装。

Android APK 当前使用调试密钥签名，仅用于个人侧载测试，默认不会由 GitHub 工作流自动发布。使用同一签名时可直接覆盖安装并保留本地店铺库；如果签名发生变化，则需要卸载旧版，同时旧版的本地数据也会被系统删除。
