# 全网日抛货源价格查询

全网日抛货源查询是一款面向发卡网商家的 Windows 桌面工具，主要用于搜索货源、筛选商品、记录价格变化以及管理商品关联。

软件在本机运行，登录和商品数据来自链动小铺官方页面及商家接口。本项目为非官方工具，与链动小铺不存在隶属或合作关系。

## 主要功能

### 货源查询与筛选

- 根据关键词和商品类型拉取货源，支持设置拉取页数。
- 提供快速、标准、稳定三档拉取速度。
- 支持售价上下限、库存、商品状态、关联状态、分类和商家筛选。
- 支持设置屏蔽词，自动隐藏名称、分类或商家中包含屏蔽词的商品。
- 支持售价从低到高、从高到低排序，以及本地分页和跨页去重。
- 查询失败或取消时保留上一次成功结果。

### 收藏与查询方案

- 收藏任意数量的商品。
- 为收藏商品添加备注和自定义标签。
- 按商品名称、商家、备注或标签搜索收藏内容。
- 保存多个查询方案，一键恢复关键词、页数、速度和筛选条件。
- 将当前筛选结果导出为 CSV，可直接使用 Excel 打开。

### 三天价格历史

- 保存收藏商品最近 3 天的售价、成本价和库存记录。
- 同一商品在 30 分钟内被多次查询时，售价和成本价分别保留最低值。
- 通过价格曲线查看收藏商品近期变化。
- 每次查询成功后，会补充刷新本次结果中没有出现且上次仍有库存的收藏商品。

### 价格与库存监控

- 显示售价、成本价、库存、状态和关联状态相较上次的变化。
- 可提示“售价较上次降低 2 元”“库存从 0 恢复到 15”等信息。
- 只有覆盖平台全部页面并完整成功的查询才会生成变化比较，避免断网或只拉取部分页面时误报下架。
- 已收藏或已关联商品从完整结果中消失时，会提示可能下架或离开当前货源范围。

### 商品关联与体检

- 支持将单个货源商品关联到自己的店铺，也支持取消关联。
- 关联前需要明确确认，不会在后台静默执行。
- 关联时可设置分类、商品名称、描述、百分比加价、固定加价、售价跟随和同步选项。
- 关联体检可检查货源状态、成本上涨、关联售价与成本差额、最低售价限制、名称/描述同步状态和关联链接可用性。
- 体检本身是只读操作，不会自动修改商品或售价。

### 本地数据与账号安全

- 密码、短信验证码等登录信息只在链动小铺官方登录窗口中输入。
- 登录凭证由 Windows 加密保存在本机，软件页面无法直接读取原始 Token 或 Cookie。
- 收藏、备注、查询方案、价格历史和监控记录保存在本机，不上传到本项目的远程服务器。
- 不包含快捷购买、自动创建订单、自动付款、验证码绕过或风控绕过功能。

## 运行要求

- Windows 10 或 Windows 11，64 位系统。
- 能正常访问链动小铺网站的网络环境。
- 已注册并完成小店开通的链动小铺商家账号；未开通小店的账号可能无法使用完整货源查询（只注册就行，其他不用管）。

当前版本不支持 Android、iOS、macOS 和 32 位 Windows。

## 下载与安装

前往项目的 [Releases 页面](https://github.com/CUy-y/source-browser-desktop/releases/latest)，在 `Assets` 中选择需要的版本：

- `链动货源查询-版本号-x64-Setup.exe`：安装版，适合长期使用，可选择安装目录并创建桌面快捷方式。
- `链动货源查询-版本号-x64-Portable.exe`：便携版，不需要安装，下载后可直接运行。
