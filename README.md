# 链动货源查询

一个在 Windows 本机运行的链动小铺商户工具。它提供货源查询、本地筛选、收藏与三天价格历史、查询方案、CSV 导出、商品关联和关联体检。

> 非官方项目，不隶属于链动小铺。登录、查询与商品关联均使用链动小铺当前官方页面或商家接口，请自行遵守平台规则。

## 主要功能

### 查询与筛选

- 按关键词和商品类型拉取 1–100 页货源。
- 快速、标准、稳定三档请求速度；快速档最多双页并发。
- 售价上下限、库存、状态、关联状态、分类、商家和屏蔽词筛选。
- 售价升序/降序、本地分页、跨页去重和字段覆盖率提示。
- 查询失败或取消时保留上次成功结果。

### 本地效率工具

- 收藏商品，保存备注和不限量自定义标签。
- 收藏数量不设上限，可按商品、商家、备注和标签搜索收藏栏。
- 保存多个查询方案，一键恢复关键词、页数、速度和筛选设置。
- 将当前筛选结果导出为带 UTF-8 BOM 的 CSV，可直接用 Excel 打开。
- 商品标题和“详情”按钮使用 Windows 默认浏览器打开官方商品页。

### 三天历史价格

- 每次查询成功后，本次结果未覆盖且上次仍有库存的收藏商品会被顺序刷新一次。
- 只记录有库存收藏商品的售价、成本价和库存。
- 同一商品 30 分钟内的重复记录合并，售价和成本价分别保留最低值。
- 每个收藏商品保留最近 3 天的历史曲线；超过 3 天的数据不会在界面显示，并会在后续快照中清理。
- 收藏刷新是辅助任务：单个收藏失败不会污染主查询结果；出现 429 时停止剩余刷新并进入请求冷却。

### 价格与关联监控

- 每次成功查询保存一份受控字段的标准化快照。
- 只有查询覆盖平台返回的全部页数且完整成功时，才与上一次完整基线比较。
- 显示售价、成本、库存、状态和关联状态变化，例如“售价较上次降低 2 元”“库存从 0 恢复到 15”。
- 失败、取消或只拉取部分页数不会生成变化事件，也不会判断商品下架。
- 完整结果中消失的已收藏或已关联商品会记录为“可能下架或离开当前货源范围”。

### 商品关联与体检

- 单商品关联和取消关联，均要求用户明确二次确认。
- 关联时支持分类、名称、描述、百分比加价、固定加价、跟随货源售价及同步设置。
- 体检项目包括货源状态、成本上涨、关联售价与成本差额、最低售价限制、名称/描述同步和关联链接。
- 关联链接会执行一次只读在线检查；体检不会自动修改商品或售价。

## 明确不包含

- 快捷购买、自动填表、创建订单、自动付款或支付跳转。
- 验证码绕过、风控绕过或免账号货源搜索。
- 后台静默关联、自动改价或批量修改商户商品。
- 云端服务、远程数据库或用户行为上传。

## 安全与本地数据

- 密码、短信验证码等只输入链动小铺官方登录窗口。
- 平台 Token 只在 Electron 主进程使用，并通过 Windows `safeStorage` 加密保存。
- 渲染页面无法读取 Token、Cookie 或 Node.js API。
- 收藏、方案、标准化快照和变化记录保存在 Electron `userData` 目录中的 `local-library-v1.json`。
- 旧版购买辅助曾保存的 `buyer-profile.bin` 会在新版启动时删除。
- 商品原始接口响应不会完整落盘；只保存本项目类型中明确列出的标准化字段。

更完整的数据说明见 [PRIVACY.md](PRIVACY.md)，架构说明见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 运行要求

- Windows 10/11 x64
- Node.js 22.12 或更高版本
- 已注册、已开通小店的链动小铺商家账号

## 本地开发

```powershell
git clone <你的仓库地址>
cd source-browser-desktop
npm ci
npm run check
npm start
```

常用命令：

```powershell
npm run typecheck   # 主进程和渲染进程类型检查
npm test            # Vitest 测试
npm run build       # 编译 Electron 主进程与 React 页面
npm run dist        # 生成 Windows 安装版和便携版
```

## Windows 打包

`npm run dist` 会在 `release/` 生成：

- `链动货源查询-<version>-x64-Setup.exe`：NSIS 安装版。
- `链动货源查询-<version>-x64-Portable.exe`：便携版。

当前项目没有配置商业代码签名。公开分发时 Windows SmartScreen 可能提示未知发布者；正式发行建议配置可信代码签名证书。

标签 `v*` 会触发 GitHub Actions 构建 Windows 产物并创建 Release。具体流程见 [docs/RELEASE.md](docs/RELEASE.md)。

## 监控语义

“最多拉取页数”可能小于平台实际总页数。例如平台共有 30 页而只设置 10 页，查询本身会成功并更新列表，但：

- 标准化快照仍会保存。
- 收藏商品仍会按规则刷新并更新价格历史。
- 不会比较涨跌、库存变化或判断下架。

当设置页数覆盖平台全部 30 页并成功完成后，才创建或更新完整监控基线。

## 项目结构

```text
src/main/       Electron 主进程、认证、查询、本地存储、导出与 IPC
src/preload/    contextBridge 最小接口
src/renderer/   React 界面与价格曲线
src/shared/     类型、运行时校验、筛选、归一化和关联体检
scripts/        清理与本地冒烟检查脚本
docs/           架构和发布文档
.github/        CI、Release 与 Issue 模板
```
